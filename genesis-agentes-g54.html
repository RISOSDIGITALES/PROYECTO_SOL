⚠️ FALTA 1 — Resolución de empresa por page_id
GET /api/n8n/pages/{page_id}
Cuando Meta envía el webhook de un comentario, el payload incluye el page_id de la página donde ocurrió el evento, pero NO el company_id de G54. El agente necesita cruzar ese page_id con la empresa correcta para cargar su configuración. Sin este endpoint usa company_id=1 (Crating Express) como fallback para todos los clientes.
// Response esperado: { "company_id": 1, "fb_access_token": "EAAxxxxx...", "ig_user_id": "17841402206774619" }
⚠️ FALTA 2 — Registro webhook en Meta (proceso externo, no es código)
El webhook community-ai-g54?company=N debe registrarse en la Meta App de cada cliente desde developers.facebook.com → Webhooks → Page. Esto lo configura el admin o el cliente una vez que tiene su Meta App creada. No es backend G54, pero es el paso que desbloquea que lleguen eventos al agente.

05 Patrón multi-tenant — para referencia de Walter
Flujo implementado en n8n (Community AI y Sales AI Motor)
Webhook (con ?company=N en la URL)
  → ⚙️ Config G54        (base URL + tokens globales)
  → 🔍 Preparar Resolución  (extrae phone_number_id o page_id del payload de Meta)
  → 🏢 Resolver Empresa     (GET /api/n8n/pages/{id} o /wa/empresa-by-phone/{id})
                          continueOnFail: true — si el endpoint no existe, sigue con fallback
  → 🏢 Aplicar Config Empresa (merge: query param > API response > fallback company=1)
  → resto del flujo con company_id dinámico
Sobre el fallback temporal: Mientras los endpoints de resolución no existen en G54, todos los mensajes se tratan como si fueran de company_id=1 (Crating Express). El query param ?company=N ya funciona hoy — cuando un cliente configura su webhook apuntando a ?company=2, ese company_id ya se usa correctamente en el flujo. El fallback solo aplica si no se pasa el query param Y el endpoint de resolución falla.
Setup por cada cliente nuevo en G54
1
Cliente crea su Meta App en developers.facebook.com (15 min)
2
Registra los webhooks apuntando a la URL con su company_id: Community AI: ...webhook/community-ai-g54?company=N · Sales AI WA: ...webhook/wa-engine-g54?company=N
3
Genera Page Access Token desde Meta Business Suite y lo sube al panel de G54
4
G54 almacena phone_number_id / page_id → la resolución automática funciona desde el primer mensaje

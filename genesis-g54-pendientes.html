Body: { estado, clasificacion, datos_actualizados, historial }
P2 Resolución de empresa por phone_number_id Para multi-tenant completo, cuando llega un mensaje WA necesitamos saber a qué empresa pertenece ese número automáticamente, sin depender del query param ?company=N. Falta: GET /api/n8n/wa-phones/{phone_number_id}
Retorna: { company_id, wa_access_token, phone_number_id }
P3 Resolución de empresa por page_id (FB) Similar al anterior pero para mensajes de Facebook/Instagram. Permite que Community AI y Sales AI sepan a qué empresa pertenece una página de FB/IG. Falta: GET /api/n8n/pages/{page_id}
Retorna: { company_id, fb_access_token, ig_user_id }

Para que sea multi-tenant real, cada empresa debe poder subir sus tokens desde el panel. Panel admin → Empresa → sección Redes Sociales → campos: fb_page_id, fb_access_token, ig_user_id.
